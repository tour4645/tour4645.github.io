## Honest Feedback
1. **Windows Security Policy**: การรัน `npx` ติดปัญหา Permission บ่อยครั้ง ทำให้ต้องสลับมาใช้วิธี Web-based แทน ซึ่งจริงๆ แล้วมันกลับง่ายกว่าสำหรับผู้ใช้
2. **Three.js Logic Complexity**: การพ่วงโบกี้รถไฟให้ติดกันและไม่ทับกันตอนเลี้ยวโค้งต้องคำนวณ `offset` ในช่วง `curve.getPointAt()` ให้แม่นยำมาก
3. **MQTT Delay**: ข้อมูลจาก DustBoy Bridge บางช่วงอาจจะหายไป ทำให้ต้องมีการสุ่มข้อมูลเบื้องต้นหรือรอจังหวะข้อมูลไหลเข้าเพื่อความสมบูรณ์ของภาพ

## Lessons Learned
- การใช้ `CatmullRomCurve3` ร่วมกับ `getDelta` เป็นหัวใจสำคัญของการทำ Animation ที่ลื่นไหลบนทุกอุปกรณ์
- การนำเสนอข้อมูลแบบ 3D Visualization (Data Towers) ช่วยให้ผู้คน "รู้สึก" ถึงความรุนแรงของฝุ่นได้มากกว่าแค่ตัวเลข 2D
- ในระบบ Windows หากเจอปัญหา Node/Npx ให้มองหาทางเลือกที่เป็น Static HTML + CDN จะช่วยลดความยุ่งยากในการติดตั้งได้มาก
